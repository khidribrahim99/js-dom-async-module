# JavaScript DOM and Async Module Tasks

This repository contains practical exercises for learning JavaScript, DOM manipulation, and asynchronous programming.

## Tasks

### Interactive To-Do List

A simple, responsive to-do list demonstrating how JavaScript can select and update DOM elements, respond to user clicks, and change CSS classes.

**Features**
- Displays a list of tasks.
- Click a task to mark it as completed or active.
- Completed tasks turn green and display a checkmark.
- Shows the number of completed tasks.
- Uses accessible button states with `aria-pressed`.

## Run the project

1. Clone or download this repository.
2. Open `tasks/todo-interactive/index.html` in a web browser.
3. Click any task to toggle its completion status.

No dependencies or build tools are required.
